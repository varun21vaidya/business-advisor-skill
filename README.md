# Business Advisor

Business Advisor is a reusable Codex skill for strategy, finance, customer research, sales, marketing, operations, and leadership. It adapts to the industry, country, business stage, and decision at hand.

## Install

Clone this repository, then copy its folder to your Codex skills directory as `business-advisor`. The directory is usually `~/.codex/skills`. Keep `SKILL.md`, `references/`, and `agents/` together. Invoke it with `$business-advisor`.

## Example

> Use $business-advisor to decide whether our B2B maintenance business should add a subscription. Ask for any missing business context, then compare the options and recommend a first test.
